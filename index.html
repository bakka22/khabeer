Android 7 and later · APK

Android may show “Unsafe app blocked” during installation.

Khabeer targets Android 9 (API 28) so its Termux environment can run installed command-line tools. Apps targeting API 29+ face restrictions on executing files in their writable app home directory. This older target can trigger a Play Protect warning about missing newer privacy protections.

If the warning says the app was built for an older Android version, tap More details, then Install anyway. Labels and available options may vary by device.

Getting started: download an APK, open it on your phone, and allow installation from your browser or file manager if Android asks. Open Khabeer, let terminal setup finish, then connect a model provider. Provider usage may have its own costs.

Already have Termux installed?

This build uses the com.termux package name, so it cannot be installed alongside Termux. A different signing key can also prevent an update. Back up your Termux files before changing installations; uninstalling removes its private data.
