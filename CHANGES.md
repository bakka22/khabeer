# Khabeer modification notice

Publication preparation date: 2026-09-06.

Khabeer is a modified Termux application maintained at https://github.com/bakka22/khabeer. Original project: https://github.com/termux/termux-app. Git history retains original authors and individual modification dates. The recorded common ancestor with the Termux checkout is 3df69d1da197dd9bd71a3bafd902dffd720576b4.

Changes include native AI chat and foreground runtime; provider routing/authentication and endpoint discovery; durable conversations; Hermes-inspired/adapted memory, identity, recall, skills, maintenance, delegation, branching, todo and plugin workflows; MCP, web tools and images; Khabeer branding/themes/settings/notifications; TermuxService notification changes; and a raw-output listener in TerminalSession.

Publication changes include documentation, copyright/license texts, offline legal access and fork-specific repository automation. Legacy automatic APK release and Termux JitPack jobs were removed.

Hermes reference checkout reviewed for attribution: 52e5e7c034edfbd0105d0b9c315c4eecb6be7f5e from NousResearch/hermes-agent. Adaptations were developed over time; this is not a universal source revision for all adaptations. Its complete MIT notice is retained in LICENSES/Hermes-Agent-MIT.txt.

The combined application is GPL-3.0-only with component exceptions. Khabeer changes are not represented as official Termux or Nous Research releases.
