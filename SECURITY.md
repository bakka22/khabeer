# Security reporting

Report Khabeer vulnerabilities privately at https://github.com/bakka22/khabeer/security/advisories/new. Do not publish exploit details, credentials or private conversations in issues. Include commit/build, Android version, reproduction steps and impact. There is no guaranteed response-time or supported-release policy yet.

Khabeer executes shell commands and connects to providers/MCP servers. Treat downloaded skills/plugins and model-requested commands as instructions/code that can affect accessible files. Read README.md's storage/privacy section before sharing logs.

For confirmed unmodified-Termux vulnerabilities, the upstream policy is https://termux.dev/security. Hermes vulnerabilities should follow NousResearch/hermes-agent security guidance. Fork-specific reports belong with Khabeer first.
